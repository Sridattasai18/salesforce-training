# Salesforce Training - Bridge Program

This repository contains the learning materials and assignments for the 5-day Bridge Program.

- **Day 1**: Introduction to Salesforce, basic navigation, and initial setup.
- **Day 2**: Data modeling, objects, fields, and relationships.
- **Day 3**: UI customization, page layouts, and record types.
- **Day 4**: Business logic with validation rules, formulas, and flows.
- **Day 5**: Introduction to Apex, SOQL, and DML operations.
